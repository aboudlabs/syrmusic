# SyrMusic

تطبيق ويب تقدّمي (PWA) لبث الموسيقى المرخّصة، عربي RTL، بتصميم زجاجي داكن (`#171326` / `#7667F8` / `#0B0A12`).
بلا اعتماديات ولا خطوة بناء: HTML + CSS + ES Modules.

## التشغيل المحلي
```bash
node tools/serve.mjs 8080     # ثم افتح http://localhost:8080
node --test tests/*.test.mjs  # الاختبارات
python3 tools/make-icons.py   # إعادة توليد الأيقونات (Pillow)
```
`localhost` يُعامل كسياق آمن، فيعمل Service Worker محلياً.

## النشر
أي استضافة ملفات ثابتة عبر **HTTPS** (Cloudflare Pages، Netlify، GitHub Pages، Vercel). عند أي تعديل على ملفات الواجهة غيّر `V` في `sw.js` (مثلاً `syrmusic-shell-v2`) ليصل التحديث للمستخدمين؛ يظهر لهم إشعار «يتوفر تحديث» ولا يُعاد التحميل تلقائياً أثناء التشغيل.
يُنصح بإضافة ترويسات: `Content-Security-Policy` (`media-src https:`, `img-src https: data:`, `connect-src 'self' https://api.audius.co`) و`X-Content-Type-Options: nosniff`. لم تُضَف كوسم meta لأنها لم تُختبر في متصفح حقيقي.

## مصدر المحتوى
**Audius** (REST عام): بحث، رائج، فنانون، ألبومات/قوائم، وبث عبر `/v1/tracks/{id}/stream`. تُستبعد المقاطع المحذوفة أو المقيّدة (`access.stream === false`).
- لا يوجد أي استخراج صوت من YouTube أو التفاف على قيود.
- مفتاح API عام اختياري (للحدود الأعلى) في `js/config.js`. **لا تضع** الـ bearer token أو الـ secret في الواجهة.
- يجب إظهار اسم الفنان (يُعرض) ومراجعة شروط Audius قبل الإطلاق التجاري.
- إضافة مصدر جديد: أضف كائناً بنفس واجهة `audius` في `js/provider.js` ضمن `sources`؛ البحث يجمع المصادر ويتحمّل فشل أحدها.

## ما يعمل في الخلفية (وما لا نضمنه)
- عنصر `<audio>` واحد طوال عمر التطبيق (التنقل عبر hash لا يعيد تحميل الصفحة).
- Media Session: العنوان والفنان والغلاف وأزرار play/pause/التالي/السابق/seek على شاشة القفل.
- لم نسجّل `seekbackward/seekforward` عمداً لأن iOS يستبدل بهما زرّي التالي/السابق.
- استمرار الصوت مع قفل الشاشة سلوك يقرره المتصفح ونظام التشغيل، وقد يختلف بين iOS (Safari / PWA مثبّتة) وAndroid (Chrome). **يجب اختباره على جهاز حقيقي** قبل الإعلان عنه.
- iOS لا يسمح للصفحة بتغيير مستوى الصوت؛ يُخفى المنزلق هناك تلقائياً.
- YouTube: لا يوجد مصدر YouTube في المشروع، لأن المشغّل المضمّن الرسمي لا يضمن التشغيل الخلفي ولا يُسمح باستخراج الصوت.

## PWA
Manifest كامل، أيقونات (any + maskable + Apple touch + favicon)، Service Worker يخزّن **هيكل التطبيق فقط**. لا يُخزَّن الصوت ولا استجابات API ولا الأغلفة، فلا بيانات قديمة مضلِّلة. التطبيق **ليس offline**: البحث والتشغيل يحتاجان إنترنت، ويظهر شريط عند الانقطاع.
iPhone: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية» (التعليمات داخل الإعدادات). Android: زر «تثبيت التطبيق» يظهر عند دعم المتصفح.

## البيانات
المفضلة والمتابَعون والقوائم والسجل وحالة المشغل في `localStorage` على الجهاز فقط (السجل قابل للإيقاف، وهناك «حذف كل بياناتي»).

## غير منفَّذ بعد (يحتاج إعداداً خارجياً)
1. **الإشعارات (Web Push)**: تحتاج خادماً + مفاتيح VAPID + جدول اشتراكات + مهمة دورية تفحص إصدارات الفنانين المتابَعين. على iPhone تعمل فقط للتطبيق المثبّت على الشاشة الرئيسية (iOS 16.4+) وبعد طلب الإذن من نقرة المستخدم. لا يوجد زر وهمي في الواجهة.
2. **الحسابات والمزامنة (Supabase)**: يتطلب مشروعاً حقيقياً وسياسات RLS، ولم يُنفَّذ؛ المكتبة محلية حالياً.
3. صفحتا الخصوصية والشروط نسخة أولية تحتاج مراجعة قانونية.
4. الإنجليزية: النصوص عربية ومجمّعة في `js/app.js`/`index.html`، ويلزم استخراجها لملف ترجمة.
